GEORGE GAMES AND TECH HUB — WEBSITE FILES

Publish on GitHub Pages:
1. Create a NEW public GitHub repository named george-games-tech-hub.
2. Open the repository, choose Add file > Upload files.
3. Upload index.html, styles.css, products.js, app.js and this README.
4. Commit the files to the main branch.
5. Go to Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch.
7. Select branch main and folder /(root), then Save.
8. Wait a few minutes. Your website should appear at:
   https://YOUR-GITHUB-USERNAME.github.io/george-games-tech-hub/
