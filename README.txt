HOW TO UPDATE ON GITHUB PAGES
1. Open your public repository: georgerobert091/george-games-tech-hub.
2. Upload/replace index.html, styles.css, products.js and app.js in the repository root.
3. Commit the changes, wait a few minutes, then refresh the live site.

HOW TO ADD MORE PRODUCTS LATER
1. Open products.js on GitHub and tap the pencil/Edit button.
2. Find the PRODUCTS array and copy one whole product object (from { to }).
3. Paste it before the final ]; and edit id, name, genre, price, description, platforms, image and imageAlt. Make sure commas between objects are correct.
4. Commit the change. The catalogue updates automatically.

IMAGE NOTE
The game cover images currently load from their image-host URLs. To store images directly in your own GitHub repository instead, upload image files into a folder named images and set each product's image value to a relative path such as images/my-game.jpg. Only use artwork you have permission to display. If a third-party image host blocks hotlinking, replace that URL with another permitted image source or your own uploaded image.
